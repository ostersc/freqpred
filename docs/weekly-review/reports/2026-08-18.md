## Recommendations

### R1 — Continue nominating a NO-only entry restriction, pending the signal team's sign-off

- **Evidence**: F1. Live YES P&L negative three consecutive weeks (−$7.10,
  −$3.59, −$6.81); pooled YES signal-level edge CI-excludes-zero-negative for
  two consecutive reports (−0.076\* over 78 mkts, then −0.040\* over 186
  mkts); pooled NO edge CI-excludes-zero-positive and growing (+0.068\* over
  93 mkts, then +0.079\* over 265 mkts).
- **Expected effect**: averaging the three windows where this is measurable,
  blocking YES entries would have turned −$7.10/+$1.47/−$8.22 into
  +$1.56/+$5.06/−$1.41 — an average of **+$5.84/week** recovered (range
  +$3.59 to +$7.11 across the three windows, computed as the negative of
  each week's YES P&L). This is a small-n estimate (14–18 YES closes per
  window) and assumes NO-side volume and edge hold if YES capital is freed
  to it, which is not tested here. This week is a reminder that "block YES"
  is a relative call, not a guarantee NO is profitable in absolute terms —
  NO itself was slightly negative this week on n=7, still smaller than YES's
  loss.
- **Risk**: unchanged from 08-11 — if this is a temporary regime rather than
  a durable model bias, blocking YES forgoes real upside when sentiment
  swings back, the same mechanism that whipsawed the opposite call in
  early August. Also needs `freqpred/signal/CLAUDE.md`-style validation
  before being treated as a signal fix rather than an entry-gate patch,
  since the root cause (why YES scores worse than NO) still isn't
  diagnosed.
- **Confidence**: medium-high. Three consecutive weeks on live P&L and two
  on the pooled CI is more legs than any of this skill's prior nominations
  have carried before acting; the narrowing YES-edge point estimate
  (−0.076 → −0.040) is the one thing keeping this from "high."
- **Verification**:
  ```bash
  docker exec freqpred-db-1 psql -U freqpred -d freqpred -c "SELECT direction, count(*) n, round(sum(pnl)::numeric,2) pnl FROM positions WHERE mode='live' AND status='closed' AND exit_time >= '2026-08-18T00:00:00+00:00' AND exit_time < '2026-08-25T00:00:00+00:00' GROUP BY direction;"
  ```
- **Revert trigger**: if next week's live YES P&L turns positive, or the
  pooled YES edge CI comes to span zero (it is trending that direction),
  drop back to watchlist. Do not implement a `directions` field on
  cumulative evidence alone without this crossing into single-digit-percent
  CI-excluding-zero territory holding for a fourth week.

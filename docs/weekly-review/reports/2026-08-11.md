### R1 — Nominate restricting new entries to NO-only, pending the signal team's sign-off

Not directly adoptable as a one-line config flip today — `StrategyConfig` has
no `directions` field (carried unchanged from the 07-28 and 08-04 reports).
This crosses from "watchlist" to "recommendation" because the explicit bar the
08-04 report set (three legs: reversal, standing negative pooled YES edge, and
a second bad live week) is now met.

- **Evidence**: F1. Live YES P&L negative two consecutive weeks (−$7.10, then
  −$3.59); live NO P&L positive both weeks (+$1.56, then +$5.06). Pooled
  signal-level edge: YES −0.076 [−0.104, −0.049]\* over 1,077/78 mkts, NO
  +0.068 [+0.049, +0.087]\* over 1,258/93 mkts — both CIs exclude zero, both
  consistent in sign for at least two consecutive reports.
- **Expected effect**: over the last two windows, blocking YES entries would
  have turned −$5.55/+$1.47 into +$1.56/+$5.06 — an average of **+$5.35/week**
  recovered (range from the two windows' actual deltas: +$3.59 to +$7.10/week).
  This is a small-n estimate (14 and 18 YES closes) and assumes NO-side volume
  and edge hold if YES capital is freed to it, which is not tested here.
- **Risk**: if this is a temporary regime (e.g. YES-favorable news cycle
  cooling, not a durable model bias), blocking YES entries would forgo real
  upside the next time sentiment swings back — exactly the mechanism that
  burned the *opposite* call three weeks ago (08-04 report: the prior
  direction-restriction idea was retired after three positive YES weeks, then
  whipsawed negative the very next week). This recommendation could whipsaw
  the same way in reverse. Also: this needs `freqpred/signal/CLAUDE.md`-style
  validation before being called a signal fix rather than an entry-gate
  tweak, since the root cause (why does the model score YES worse than NO)
  hasn't been diagnosed — this nomination only says "block," not "fix."
- **Confidence**: medium. Two consecutive weeks each on live P&L and pooled
  edge is more legs than the whipsawed 08-04 call had, but this skill's own
  rule against single-week action is a soft floor, not a strong one — I'd
  want a third week before treating this as settled.
- **Verification**:

  pooled YES signal-level edge CI comes to span zero, drop this back to
  watchlist — do not implement the `directions` field on a single confirming
  week beyond this one.

3b. TRAILING STOP SWEEP  (real price paths; profit-only trail)
   Unlike a fixed take-profit, a trailing stop never caps a winner — it exits
   only after a reversal from the peak. On the first leg it pre-empts the real
   exit only if it fires earlier; otherwise the real exit stands.
   READ THE 'with re-entry' COLUMN. A trail firing above its trigger always
   exits in PROFIT, and risk.py's cooldown blocks only on a LOSING close — so
   nothing stops the strategy re-entering the same market on its next signal.
   Scoring the exit alone credits a saving the book never keeps: each re-entry
   re-exposes capital to the same admitted-signal edge, so on a negative-edge
   book the trail multiplies the losses it appears to prevent. 'no re-entry' is
   an upper bound needing a block on re-entry after a PROFITABLE trailing exit,
   which no current config option expresses.
   Re-entry is modelled permissively (min_confidence + the real limit price
   only — no exposure caps, mid-price band, max_edge or max_days_to_close), so
   the re-entry count is an over-estimate. Offsets at or inside the typical
   spread are not tradeable; check the spread before believing a tight row.
